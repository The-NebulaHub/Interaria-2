# INTRODUÇÃO

O Projeto Integrador **"Mapeando as Juventudes de Camaçari"** tem como objetivo investigar, registrar e valorizar as diversas manifestações culturais presentes entre os jovens do município. A proposta busca compreender como diferentes formas de expressão, como música, graffiti, slam, hip-hop, cultura digital e práticas religiosas, contribuem para a construção da identidade juvenil local.

Além da pesquisa sobre as juventudes de Camaçari, o projeto também promove o desenvolvimento de competências tecnológicas por meio da utilização das ferramentas **Git** e **GitHub**. Dessa forma, os participantes aprendem a trabalhar de maneira colaborativa, organizada e alinhada às práticas utilizadas no mercado de tecnologia.

# RESUMO

Este projeto consiste na criação de um repositório digital colaborativo destinado ao mapeamento e à documentação das expressões culturais das juventudes de Camaçari. O trabalho foi desenvolvido em equipes, utilizando Git e GitHub para gerenciar versões, organizar contribuições e integrar os conteúdos produzidos.

Durante o processo, os grupos realizaram pesquisas sobre diferentes manifestações culturais da cidade, registrando informações em arquivos Markdown e compartilhando os resultados por meio de *branches*, *commits* e *pull requests*. Além de ampliar o conhecimento sobre a diversidade cultural local, o projeto proporcionou experiência prática com ferramentas amplamente utilizadas no desenvolvimento de software, fortalecendo habilidades de colaboração, organização e trabalho em equipe.
